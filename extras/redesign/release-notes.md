An unofficial build of VLC 4 (development version) with the interface restyled after Juxtopposed's "VLC Redesign" Figma Community design.

**Windows 10/11, 64-bit.** Download the zip below, unzip it anywhere and run `vlc.exe`. There's no installer. The build runs in portable mode, so it keeps its own settings and won't touch a VLC you already have installed.

The first launch can take about half a minute while Windows checks the new files. VLC 4 is still in development, so expect the occasional bug.
